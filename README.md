# 规范智能检索与问答系统

面向工程建设从业者的本地化规范检索与管理工具。将分散的施工规范文本（国标、行标等）导入为结构化条文库，提供全文检索、分类管理、规则自动分类、AI 智能问答等能力。

> 规范资料取自公开渠道，仅供个人学习，禁止商用，侵权请联系删除；OCR 识别可能存在错漏，检索及 AI 回复仅作参考，不得作为专业评估、工程决策依据，请以官方规范原文为准。

## 功能特性



* **规范导入**：支持 Markdown 等文本格式导入，AI 校核规范名称有效性，自动解析为条文。

* **全文检索**：关键词搜索 + 状态筛选（现行 / 修订中），支持 CE 精排与多维分类过滤。

* **规范管理**：规范与条文的查看、编辑、分类、删除，支持批量重新分类。

* **分类规则**：关键词规则 + AI 批量分类，人工审核确认后生效。

* **词库管理**：同义词 / 别名 / 易混淆术语，支持 CSV 批量导入，扩展检索召回。

* **AI 智能问答**：原文摘抄 / 综合问答两种模式，回答标注规范条文来源。

* **知识库维护**：健康检查、向量索引重建、数据备份、运行日志、参数设置。

## 技术栈



* 后端：Python 3 + FastAPI + Uvicorn

* 存储：SQLite（含 FTS 全文索引）+ LanceDB 向量索引

* 前端：Jinja2 模板 + 原生 JS（轻量、无前端构建链）

* AI：支持 Claude Code / Codex / 豆包 / DeepSeek / GLM / Kimi / 自定义 后端接入

## 快速开始

### 环境要求



* Python 3.10+

* pip

### 安装与配置



```
# 1. 安装依赖
pip install -r requirements.txt

# 2. 配置环境变量（复制示例并修改）
cp .env.example .env
# 按需修改 .env 中的 SECRET_KEY、DATABASE_PATH、LANCE_DB_PATH 等

# 3. 创建管理员账号（默认 admin / admin123，可自定义）
python scripts/create_admin.py --username admin --password admin123

# 4. 启动服务
uvicorn app.main:app --host 127.0.0.1 --port 8023
```

启动后浏览器访问 [http://127.0.0.1:8023](http://127.0.0.1:8023)，使用管理员账号登录。

### 导入规范

登录后点击左侧「导入规范」，填写规范编号与名称（可先点击「校核有效性」由 AI 校验名称），选择规范文件后点击「开始导入」。详细使用说明见 `docs/使用说明/`。

## 目录结构



```
app/          # 后端应用（路由、解析、检索、AI、维护等模块）
scripts/      # 运维脚本（创建管理员、重建索引等）
static/       # 前端静态资源
tests/        # 测试
data/         # 运行时数据（数据库、上传目录）
docs/         # 使用说明文档
```
