两处改动对应你的两点意见：①「确认并继续导入」点击后白蒙版遮罩并禁用（防重复提交）；②校核有效性状态下拉与「状态：」垂直居中、下拉箭头不再与文字重叠。③规范管理状态列下拉经你实测为窗口宽度不足所致，无需改动（见 §3）。本页可交互：点按钮、切换下拉值查看效果。

参照「开始导入」按钮方案：点击提交后按钮整体盖白蒙版（rgba(255,255,255,.55) + 虚线边框）+ disabled，防止重复点击重复提交；文案同步变「提交中…」。点击下方按钮可体验（2 秒后恢复，演示用；真实场景提交后页面进入导入进度轮询，不会恢复）。

§2 导入对话框 · 校核有效性状态下拉 对应意见②

根因：Pico 的 select 用 appearance:none + 背景箭头（定位 center right .75rem），默认 padding-right:2.5rem 给箭头留位；内联 padding:.15rem .3rem 把右侧留白压成 0.3rem → 文字穿进箭头区重叠。修复：padding-right:1.9rem 留出箭头空间；height:1.9em + line-height:1.4 与「状态：」文字同量级，flex 下垂直居中。

§3 规范管理 · 状态列下拉 用户实测：无需改动

结论：不实施。用户实测该页状态列下拉的文字/箭头重叠是窗口宽度不足造成（表格挤压导致下拉被压缩），并非样式缺陷；窗口拉宽后正常，故不为此改动。specs_table.html 保持现状。
