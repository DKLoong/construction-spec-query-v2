# 1 总则
1.0.1 为规范建筑工程冬期施工行为，保证工程质量，制定本规程。
1.0.2 本规程适用于建筑工程冬季施工的施工准备、技术措施和质量管理。
# 2 基本规定
2.0.1 冬期施工期限应根据当地气象资料确定，当室外日平均气温连续5天稳定低于5℃即进入冬期施工。
2.0.2 冬期施工应编制专项施工方案，并应针对工程特点进行技术交底。
2.0.3 冬期施工应采取防滑、防冻、防风、防火等安全措施。
# 3 土方工程
3.1.1 冬期挖土时，应防止地基受冻，开挖后应及时采取保温覆盖措施。
3.2.1 冬期回填土每层铺土厚度应比常温施工时减少20%～25%。
3.3.1 冻土区回填应采用未冻的砂类土、碎石类土等透水性好的土料。
# 4 钢筋工程
4.1.1 冬期施工的钢筋冷拉、冷弯温度不应低于-20℃。
4.2.1 钢筋负温焊接宜采用闪光对焊、电弧焊，焊接时应采取防风、保温措施。
# 5 混凝土工程
5.1.1 冬期施工的混凝土宜选用硅酸盐水泥或普通硅酸盐水泥。
5.2.1 混凝土受冻临界强度：采用硅酸盐水泥或普通硅酸盐水泥配制时，不应低于设计强度等级值的30%。
5.3.1 冬期混凝土养护应采用蓄热法、暖棚法、蒸汽养护法等方法。
5.4.1 混凝土测温孔应按规范要求布置，测温频次应符合本规程规定。
5.5.1 负温下浇筑混凝土应掺用防冻剂，防冻剂进场应进行复验。
# 6 砌体工程
6.1.1 冬期砌筑采用掺盐砂浆法时，砂浆使用温度不应低于5℃。
6.2.1 砌体冬期施工应对砌筑砂浆、砖石材料采取保温防冻措施。
# 7 保温与测温
7.1.1 冬期施工应做好原材料、成品和半成品的保温防护。
7.2.1 测温记录应及时整理归档，作为工程质量验收的依据。
