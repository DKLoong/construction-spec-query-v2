# 1 总则
1.0.1 为统一混凝土结构工程施工质量验收方法，加强工程质量管理，保证工程质量，制定本规范。
1.0.2 本规范适用于建筑工程混凝土结构工程施工质量的验收。
1.0.3 混凝土结构工程施工质量验收除应符合本规范外，尚应符合国家现行有关标准的规定。
# 2 术语
2.1.1 混凝土结构 以混凝土为主制成的结构，包括素混凝土结构、钢筋混凝土结构和预应力混凝土结构等。
2.1.2 现浇结构 在现场支模并整体浇筑而成的混凝土结构。
2.1.3 装配式结构 在工厂或现场预制，经装配、连接而成的混凝土结构。
2.1.4 缺陷 混凝土结构工程质量不符合设计或验收标准要求的项目。
# 3 基本规定
3.0.1 混凝土结构工程施工质量验收应划分为单位工程、分部工程、分项工程和检验批。
3.0.2 检验批质量验收合格应符合下列规定：主控项目的质量经抽样检验均应合格；一般项目的质量经抽样检验合格。
3.0.3 混凝土结构子分部工程施工质量验收合格应符合本规范有关规定。
3.0.4 对涉及结构安全和使用功能的重要分部工程应进行抽样检测。
# 4 模板分项工程
4.1.1 模板及其支架应根据工程结构形式、荷载大小、地基类别、施工设备和材料供应等条件进行设计。
4.1.2 模板及其支架应具有足够的承载能力、刚度和稳定性，能可靠地承受浇筑混凝土的重量、侧压力以及施工荷载。
4.2.1 模板安装应满足下列要求：模板的接缝不应漏浆；模板与混凝土的接触面应清理干净并涂刷隔离剂。
4.2.2 浇筑混凝土前，模板内的杂物和钢筋上的油污应清理干净。
4.3.1 模板拆除时，混凝土强度应符合设计要求；当设计无要求时，侧模应在混凝土强度能保证其表面及棱角不受损伤时拆除。
# 5 钢筋分项工程
5.1.1 钢筋进场时，应按国家现行相关标准的规定抽取试件作屈服强度、抗拉强度、伸长率和重量偏差检验。
5.1.2 钢筋应平直、无损伤，表面不得有裂纹、油污、颗粒状或片状老锈。
5.2.1 钢筋加工的形状、尺寸应符合设计要求，其偏差应符合本规范表的规定。
5.2.2 箍筋弯折处不应小于135度，弯后平直段长度不应小于箍筋直径的10倍。
5.3.1 钢筋连接宜采用机械连接、焊接连接或绑扎搭接连接。
5.3.2 钢筋机械连接接头应按规定进行工艺检验和现场抽检。
5.4.1 钢筋安装时，受力钢筋的品种、级别、规格和数量必须符合设计要求。
5.4.2 钢筋安装位置的偏差应符合本规范表的规定。
# 6 预应力分项工程
6.1.1 预应力筋进场时，应对其品种、规格、级别和数量进行检验。
6.2.1 预应力筋张拉时，混凝土强度应符合设计要求；当设计无要求时，不应低于设计强度等级值的75%。
6.3.1 孔道灌浆应采用强度等级不低于M30的水泥浆，灌浆应饱满、密实。
# 7 混凝土分项工程
7.1.1 混凝土原材料进场时，应按规定进行检验。
7.1.2 水泥进场时应对其品种、代号、强度等级、包装或散装仓号、出厂日期等进行检查。
7.2.1 混凝土应按国家现行相关标准规定进行配合比设计。
7.2.2 首次使用的混凝土配合比应进行开盘鉴定。
7.3.1 混凝土运输、输送、浇筑过程中严禁加水。
7.4.1 混凝土浇筑完毕后，应及时进行养护，养护时间应符合设计要求。
7.4.2 混凝土试件应在浇筑地点随机抽取，标准养护试件留置应符合本规范规定。
# 8 现浇结构分项工程
8.1.1 现浇结构的外观质量不应有严重缺陷，对已经出现的严重缺陷应由施工单位提出技术处理方案。
8.1.2 现浇结构不应有影响结构性能和使用功能的尺寸偏差。
8.2.1 现浇结构的外观质量缺陷，应根据其影响结构性能、使用功能和外观观感的程度，按本规范规定进行判定。
