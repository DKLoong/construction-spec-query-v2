# 1 总则
1.0.1 为规范扣件式钢管脚手架的设计、施工与验收，保证施工安全，制定本规范。
1.0.2 本规范适用于房屋建筑工程和市政工程等施工中扣件式钢管脚手架的设计、搭设、使用与拆除。
# 2 术语
2.1.1 扣件式钢管脚手架 由钢管杆件和扣件连接而成的脚手架。
2.1.2 剪刀撑 在脚手架外侧交叉设置的斜杆。
# 3 构配件要求
3.1.1 脚手架钢管宜采用外径48.3mm、壁厚3.6mm的焊接钢管。
3.1.2 扣件应采用可锻铸铁或铸钢制作，其质量和性能应符合现行国家标准的规定。
3.2.1 脚手架搭设前应检查钢管有无严重锈蚀、弯曲、压扁或裂纹。
# 4 荷载
4.1.1 脚手架荷载分为恒荷载、活荷载和风荷载。
4.1.2 脚手架的承载能力应按概率极限状态设计法的要求采用分项系数设计表达式进行设计。
# 5 设计计算
5.1.1 纵向水平杆、横向水平杆、立杆等构件的受弯构件强度与挠度应满足本规范规定。
5.2.1 立杆稳定性应按本规范规定的计算长度和长细比进行验算。
5.3.1 连墙件的强度、稳定性和连接强度应进行计算。
# 6 构造要求
6.1.1 立杆间距、步距应根据脚手架用途和荷载确定，最大间距应符合本规范规定。
6.2.1 剪刀撑应沿脚手架外侧立面连续设置，角度宜为45°～60°。
6.3.1 连墙件应靠近主节点设置，偏离主节点的距离不应大于300mm。
# 7 搭设与拆除
7.1.1 脚手架必须配合施工进度搭设，一次搭设高度不应超过相邻连墙件以上两步。
7.2.1 拆除作业必须由上而下逐层进行，严禁上下同时作业。
7.2.2 连墙件必须随脚手架逐层拆除，严禁先将连墙件整层或数层拆除后再拆脚手架。
# 8 检查与验收
8.1.1 脚手架搭设完毕应按规定进行验收，验收合格后方可投入使用。
8.1.2 使用过程中应对脚手架进行定期检查和维护。
